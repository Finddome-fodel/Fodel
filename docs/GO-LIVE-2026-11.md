**Sanity query** (new query, after 0058; all in one):

```sql
select
  (select services -> 'pricingLive' from site_settings where id = 1) as pricing_live,
  (select count(*) from information_schema.columns where table_name = 'properties' and column_name in ('package_months','price_tier_index','price_tier_huf_bounds')) as term_columns,
  (select string_agg(e::text, ', ' order by e::text) from unnest(enum_range(null::listing_package)) e) as package_values,
  (select string_agg(e::text, ', ' order by e::text) from unnest(enum_range(null::locale_code)) e where e::text in ('sr','uk','tr','he','ar','ru','zh')) as new_locales,
  to_regclass('public.exchange_rate_snapshots') as fx_table,
  has_table_privilege('anon', 'public.exchange_rate_snapshots', 'select') as fx_anon_can_read,
  (select count(*) from properties where property_subtype = 'agricultural-estate') as old_agricultural_estate,
  (select count(*) from pg_policies where schemaname = 'storage' and tablename = 'objects' and policyname = 'property_media_objects_read' and roles = '{authenticated}') as photo_bucket_policy;
```

Expected: `pricing_live` **true** · `term_columns` **3** · `package_values` contains **basic, europe, world** (and the two old ones) · `new_locales` **ar, he, ru, sr, tr, uk, zh** · `fx_table` **exchange_rate_snapshots** · `fx_anon_can_read` **true** · `old_agricultural_estate` **0** · `photo_bucket_policy` **1**.

## Step 7: e-mail deliverability (SPF, DKIM, DMARC)  **MARCI**

Status at the last test: mail from info@finddome.com still landed in freemail spam. **This is likely also why a new uploader's "set your password" e-mail did not arrive**; the registration code was not changed in this release and works (it logs `[email] accepted … id=…` on success).

1. Resend → **Domains** → `finddome.com` (if missing: Add Domain, region EU).
2. Copy the records Resend shows **exactly** into the DNS provider of finddome.com. Typically: `MX send` → `feedback-smtp.eu-west-1.amazonses.com` priority 10; `TXT send` → `v=spf1 include:amazonses.com ~all`; `TXT resend._domainkey` → the long `p=…` key.
3. Add DMARC: `TXT _dmarc` → `v=DMARC1; p=none; rua=mailto:info@finddome.com; adkim=r; aspf=r`. After 2–4 clean weeks change `p=none` to `p=quarantine`.
4. Do not touch the root `@` SPF if a mailbox provider (e.g. Google Workspace) uses it; Resend uses the `send.` subdomain. One SPF record per hostname only.
5. Resend → **Verify DNS Records** (up to 24 hours).
6. Send a test to a Gmail and a freemail address; **Show original** must say SPF, DKIM, DMARC = **PASS**.
7. The app's `from` address must be on the verified domain (default `FINDDOME <info@finddome.com>`, or `FODEL_FROM` in Vercel).
